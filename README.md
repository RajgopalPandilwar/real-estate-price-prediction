# Real Estate Price Prediction

A machine learning project for predicting real estate prices based on property features. Built with Python and scikit-learn.

## Author

**Rajgopal Pandilwar**


## Overview

This project uses regression models to predict house prices based on features like location, square footage, number of bedrooms, and other property attributes. It includes data preprocessing, feature selection, and model evaluation.

## Requirements

```bash
pip install pandas numpy scikit-learn matplotlib seaborn
```

## Usage

```bash
python real_estate_price_prediction.py
```

## Project Structure

- `real_estate_price_prediction.py` — Main script with data analysis and model training
- `requirements.txt` — Python dependencies
